Zifo task app — low-level design

AWS account 229691749767 · region ap-southeast-2 · CloudFront distribution E4EDW133P7EXJ

The browser talks to one hostname: https://d1fh72q9mw0l25.cloudfront.net. That is CloudFront. React uses relative paths such as /api/auth/login and /api/tasks. It never calls S3, ECS, or RDS directly. Locally, nginx on port 3000 (or Docker 9000) did the same job.

1. Dummy story

  1. Person opens the CloudFront URL (HTTPS 443). That is the shop front.
  2. HTML/JS/CSS come from a locked S3 cupboard. Only CloudFront has the key (OAC + bucket policy).
  3. Login and tasks go through an ALB receptionist: /api/auth* → auth container, /api/tasks* → task container.
  4. Each container uses its own Postgres database on one RDS instance. Secrets live in Secrets Manager, not in GitHub.

Function spa-index-rewrite is on the S3 behavior only. API behaviors must not use it, or /api/auth/login would become HTML.

9. Production readiness

As-built is in AWS or git. Intended was specified for the ECS console (desired count 2, CPU autoscale 2–4) and must be confirmed there. Not built is out of scope for this demo.

Private networking

This is a demo network, not a fully private backend. Fargate public IP is on (ECR pull without NAT). ALB security group allows 80 from 0.0.0.0/0. CloudFront talks HTTP to the ALB. RDS 5432 is only from the ECS SG. Prod would use private subnets, no public IP, NAT or VPC endpoints, CloudFront prefix list on the ALB, and HTTPS to the origin.

Security

Controls in place: private S3 + OAC, CloudFront HTTPS and SPA headers, JWT in Redux, refresh HttpOnly cookie, bcrypt, parameterized SQL, Secrets Manager, SG allow-lists, API cache disabled with Authorization forwarded. This file is not a pentest or IAM Access Analyzer sign-off.

Do not treat the ALB DNS or the S3 website URL as the product. Do not put JWT in localStorage. Do not attach spa-index-rewrite to API behaviors. After a frontend deploy, invalidate CloudFront /index.html if the UI looks stale. Confirm desired count and autoscaling in the ECS console if you have not saved them yet.
